MÉTABOSCOPE
===========

Installation
1. Décompresser le dossier complet.
2. Ouvrir Levures_TP3_avec_images.html dans Chrome, Edge, Firefox ou Opera.
3. Aucune installation et aucune connexion Internet ne sont nécessaires.

Contenu pédagogique
- rôle du glucose dans la multiplication des levures ;
- témoin et comparaison des résultats ;
- métabolisme, énergie et matière ;
- respiration et fermentation ;
- raisonnement : observation, explication, conclusion.

Le cours s'ouvre depuis l'accueil. Le jeu fonctionne entièrement en local.
Aucun nom, score ou autre donnée n'est envoyé ni enregistré.
